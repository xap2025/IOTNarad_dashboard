# Logo Files Directory

## Save Your Xaptronics Logo Here

Please save your Xaptronics logo image file in this directory with one of these names:

- `xaptronics-logo.png` (recommended)
- `xaptronics-logo.jpg`
- `xaptronics-logo.svg`

## Recommended Logo Specifications

- **Format**: PNG (with transparent background) or SVG
- **Size**: 200x200 pixels or higher
- **Background**: Transparent or white
- **File Size**: Under 500KB for best performance

## How to Add Your Logo

1. Save your logo image file in this folder: `assets/images/xaptronics-logo.png`
2. The dashboard will automatically display it in the sidebar
3. If you want to change the logo, just replace the file with the same name
